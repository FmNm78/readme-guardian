# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/FmNm78/readme-guardian/security/advisories/new) feature for this repository.

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, code, or configuration

We will acknowledge your report and work with you on a fix and coordinated disclosure timeline.

## Supported Versions

This project is pre-1.0 and does not yet maintain multiple supported release branches. Security fixes are applied to the latest version on `main`.
